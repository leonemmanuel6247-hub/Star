# Polices embarquées StarOffice Writer

Ces polices sont chargées dans l'éditeur (expo-font) et embarquées en
base64 dans le HTML d'impression / PDF (@font-face). Graisses : normal (400)
+ gras (700). L'italique est synthétisé par le moteur de rendu.

| Ubuntu | Ubuntu-Regular.ttf, Ubuntu-Bold.ttf | google/fonts (`ufl/ubuntu`) | Ubuntu Font Licence 1.0 |
| DejaVu Sans | DejaVuSans.ttf, DejaVuSans-Bold.ttf | matplotlib (mpl-data, PyPI) | Licence DejaVu (libre) |
| Liberation Sans | LiberationSans-Regular.ttf, LiberationSans-Bold.ttf | @typopro/dtp-liberation (npm, build TypoPRO) | SIL OFL 1.1 |

Toutes ces licences autorisent l'embarquement et la redistribution dans
l'application. Poids total : ~2,8 Mo.
